# T7 · `pair` command for mirrored servos · C023

**Branch** `night/pca9685-pair` → PR to `dev`
**Budget** one evening (firmware + host test + docs)

## Goal
In the bench env `pca9685`, add `pair <chA> <chB> <deg> [deg_per_s]`: both servos move together, chB mirrored, so the two arms (TD-8120MG, facing each other) lift the U in step.

## Context
- Card C023 (t-r1b-drive). Servos: TD-8120MG, 500–2500 µs, 180°.
- Mirror around 1500 µs: `us_A = 500 + deg/180 × 2000`, `us_B = 3000 − us_A`.
- Default ramp 20 °/s; both channels ramp in lock-step (same deg value each tick, not two independent ramps).
- Proposed channels CH10/CH11 (CH0/1 ESCs, CH2–5 BTS7960, CH6 buzzer, CH7–9 LEDs). **VERIFY** in `hardware/wiring/PINOUT.md`: it has no PCA9685 channel table yet. If none, add one (source: this card) instead of guessing.
- Servo power: Jesverty bench supply at 6.0 V, CC 3 A (not 5.0 V / 1 A as in the single-servo protocol).
- `dm` dead-man and rocker `kill` must drop BOTH pulses, same as `ch`/`sweep`.
- Respect the existing `limit` window; refuse a `pair` if either computed pulse is outside it.

## Files to create / change

## Tests
- deg 0 → A 500 / B 2500; 90 → 1500 / 1500; 180 → 2500 / 500; 215 → refused (out of range).
- A + B == 3000 for every deg in 0..180.
- Ramp: 0 → 90 at 20 °/s takes 4.5 s ± 1 tick.
- `scripts/check.sh` passes.

## PROTOCOL steps (to write)
1. Linkages OFF: `dm 10000`, `pair 10 11 90` → both horns centre; `pair 10 11 45` → mirrored; KILL drops both.
2. Arms ON, empty U: `pair 10 11 <lift>` slowly, record current at the Jesverty.
3. With Pesho (C021) in the U: same, record current and photos.
