## Goal
1. A per-channel pulse offset so the two cradle servos can be matched after the arms are clocked on the splines (25T ≈ 14.4° per tooth, so the arms never line up exactly).
2. Fix the rocker wiring text in the pca9685 PROTOCOL.

## Context
- Card C023 (t-r1b-drive). First powered lift 22–23.10: arms clocked at different angles → servos fought, two arm screws sheared (FAILS 172). After re-clocking the empty U lifts level (C023_15), but a few degrees of mismatch remain.
- `pair` today: `us_A = 500 + deg/180 × 2000`, `us_B = 3000 − us_A` (PairMath.h).

## Change
- Command `trim <ch> <us>`: signed offset, −200..+200 µs, per channel, default 0. Stored in RAM only (no NVS yet). `trim` alone prints both trims.
- `pair` applies it after the mirror: `us_A' = us_A + trim[chA]`, `us_B' = us_B + trim[chB]`. The soft-window check (`pairInWindow`) uses the trimmed pulses.
- Pure function in `PairMath.h` (e.g. `pairFromDegTrim(deg, trimA, trimB)`), host-tested.
- `?` / state line shows `trimA` / `trimB`. Help line for `trim`.

- 90 with trimB = −60 → 1500 / 1440.

## PROTOCOL fix (`firmware/bench/src/pca9685/PROTOCOL.md`)
- §1 says "rocker RUN pole → OE → GND" and "GPIO14 → rocker KILL pole". One SPDT cannot do both, and it contradicts PINOUT / breadboard 2b. Write the bench wiring that was used 22.10: **rocker C → GPIO14, KILL → GND, 10 k GPIO14 → 3V3; PCA9685 OE left open** (the module has 10 k OE → GND, outputs enabled). On the breadboard the rocker is a software stop; the hardware stop is the bench supply OUTPUT button. Hardware OE kill comes with carrier rev B (Q2).
- §3: monitor on the **left** USB-C (`/dev/cu.usbmodem…`), this env keeps CDC_ON_BOOT=1.
- §7 Pair: add "clock both arms at `pair 10 11 90` before connecting the U; current > 0.3 A standing still = fighting → KILL" and the `trim` step.
