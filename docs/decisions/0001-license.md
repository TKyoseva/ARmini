# 0001 · Licence

Status: decided 2026-10-09.

- **Code** (firmware, tools, scripts, CAD and PCB generator scripts): MIT.
- **Hardware design files** (OpenSCAD, KiCad, STL), **documentation and images:** CC BY 4.0.

Why two: code and hardware have different standard licences. CC BY 4.0 was chosen over CERN-OHL-P v2 for the hardware because it is one licence for both drawings and documents, and anyone can reuse the work as long as they credit it.

Open before the repository goes public: check with the mentor (John Hood, Horizon Academic) that nothing in `sim/` is bound to Horizon Academic. Until then `sim/` is excluded from the MIT licence ("all rights reserved").
